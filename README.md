# ABI OOH LDA Compliance Hub — Streamlit v6 (BETA)

## What changed in v6
- Automatic geographic tiling replaces the 18 km square restriction. Each occupied tile queries OSM with a halo beyond the screening buffer.
- Tile retrieval failures stop the whole screening run rather than treating missing areas as clear.
- A 250 km maximum regional span and 160-tile safety cap remain; large jobs can take substantial time.

## Existing v5 features
- Leaflet/Folium map replaces PyDeck. Map includes a two-click ruler that updates in **feet** as you move the mouse.
- Red and yellow 250'/500' polygons are generated by buffering **actual OSM footprint geometries** in a projected CRS. These are not circles around address pins.
- Toggle restricted buffers, university buffers, 50' review bands, and facility pins. Only polygons near currently filtered placements are drawn; a 450-facility display cap applies, but not to screening.
- Point-only and incomplete OSM geometries can generate **Needs more screening**, not an authoritative footprint polygon. No facility source is treated as legal clearance.
- Common financial columns are stripped from the internal result and export. **You must still sanitize and obtain approval before uploading campaign inventory to any externally hosted service.**
- Editable recommendation table and Google My Maps CSV exports remain.

## Install / deploy
Replace `streamlit_app.py`, `requirements.txt`, and `.streamlit/config.toml` in your existing Streamlit repo, then commit and redeploy. For local use: `pip install -r requirements.txt` and `streamlit run streamlit_app.py`. No login in this beta; **do not use real confidential inventory on a publicly accessible app**.

## Important screening limitations
- This is NOT a verified port of the Colab v47 engine and NOT legal compliance certification.
- OSM data may be missing, outdated, incompletely tagged, or use point features instead of building outlines. An untagged building may not be found even if a nearby church/school exists. The Middle Collegiate Church / MN-03-123273-L case is a **known unresolved regression test**, not a confirmed fix.
- Relation geometry is approximated from available closed outer rings; holes and incomplete rings may not be accurate. Point-only geometries are review flags rather than footprint-based red flags.
- For each upload, use a single screening distance; this beta is limited to a 250 km regional span, 160 occupied geographic tiles, and 3,000 placements. The local UTM approximation should be validated for large regions.
- Measurement ruler is straight-line point-to-point feet. Regulatory screening uses shortest distance to the retrieved mapped facility geometry, which can differ.
- The 50' review band is a workflow flag, not a legal expansion of the 250'/500' zone.
- Use a verified facility footprint and applicable legal boundary definition for final decisions.

## Google My Maps
Download the ZIP after reviewing placements. Import `03_MyMaps_Recommended_Placements.csv`, select Latitude/Longitude and Placement ID, and style by Screening Status. Facility reference pins are in `02_Matched_OSM_Facilities.csv`. My Maps publishing remains manual.

## Validation before production
Compare the 20 LinkNYC placements to Colab v47, verify the source OSM geometry for Middle Collegiate Church at 104 Second Avenue, and investigate the earlier 2-versus-15 conflict discrepancy. Until these pass, do not rely on green statuses for clearance.
